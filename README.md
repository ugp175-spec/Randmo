## 💡 About Randmo

**Randmo** is a web-based random generator toolkit designed to make everyday random decisions easier and more enjoyable.

Whether you want to generate a password, roll a dice, select a random country, pick a random date, or make a quick decision, Randmo provides different tools through one simple interface.

## ✨ Features

- 🎯 14 Random Tools
- 🔍 Search and Explore
- ❤️ Favorites
- 📌 Save Results
- 🕘 Generation History
- 📋 Copy to Clipboard
- 📱 Responsive Design
- 💾 Browser Local Storage

## 🛠️ Available Tools

| No. | Tool | Description |
|---|---|---|
| 1 | Random Number | Generate random numbers within a range. |
| 2 | Coin Flip | Get Heads or Tails. |
| 3 | Dice Roll | Roll a virtual dice. |
| 4 | Random Color | Generate random colors. |
| 5 | Password Generator | Generate random passwords. |
| 6 | Yes or No | Get a random answer. |
| 7 | Random Letter | Pick a random alphabet letter. |
| 8 | Random Date | Generate a random date. |
| 9 | Random List | Select random items from a list. |
| 10 | Rock Paper Scissors | Play the classic game. |
| 11 | Random Country | Discover a random country. |
| 12 | Chemical Element | Explore a chemical element. |
| 13 | Powerball Picker | Generate lottery-style numbers. |
| 14 | Random Palette | Generate a random color palette. |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ugp175-spec/Randmo.git
```

### 2. Navigate to the project directory

```bash
cd Randmo
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### 5. Build for production

```bash
npm run build
```

## ⚙️ How It Works

1. Choose a generator.
2. Enter the required information.
3. Generate a random result.
4. Copy or save the result.
5. Access saved results and history whenever needed.

*Note: Saved information is stored in the browser using Local Storage.*
