# Randmo

A simple React + Vite random tools website built for a Web Technology project.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Features

- 14 random tools
- Search and category filters
- Copy generated results
- Save favorite results using localStorage
- Recent generation history
- Responsive layout
- Separate CSS files for components and pages

All data is stored in the browser. No backend is required.
